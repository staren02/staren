# STAREN Portfolio — V5

A restrained, abstract personal portfolio for Staren Soba.

## What V5 focuses on
- Editorial / abstract visual language rather than cyberpunk or sci-fi styling
- Natural, non-generic portfolio copy
- Responsive layout and accessible keyboard interactions
- Subtle scroll progress and motion
- Project notes / modal interactions
- Public GitHub repository feed with an offline fallback
- Staren's three uploaded photos, kept in the requested priority order

## Run
Open `index.html` in a browser, or serve the folder with any simple static server.

## GitHub
The live repository section requests public repositories from `staren02` through the GitHub public API when an internet connection is available. It falls back to the GitHub profile if the request fails.
